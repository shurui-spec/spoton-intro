# SpotOn 一頁式互動介紹頁｜規格書

> 課堂作業：用 Vibe Coding 做出一個互動網頁
> 作者：Shurui（國立中山大學）　版本：v1.0（2026-10-19）

---

## 1. 專案概述

**SpotOn** 是我正在開發的表演藝術選位輔助工具，正式版是 Vue 3 網頁 App（部署於 Vercel）。它的核心想法是：觀眾買票時通常只能看價格和平面座位圖「猜」位置好不好，SpotOn 讓使用者選定座位後，看到這個位置的**視野截圖**，以及依照自己**音樂經驗程度**調整過的**聲音描述**。

這次作業不重做整個 App，而是做一個**一頁式互動介紹頁**：讓沒用過 SpotOn 的人在 2–3 分鐘內，先意識到「選位其實在用猜的」，再親手體驗一次 SpotOn 的選位流程。

## 2. 目標受眾與使用情境

| 項目 | 內容 |
|---|---|
| 主要受眾 | 作業老師與同學 |
| 使用情境 | 在課堂上或課後用電腦／手機打開連結瀏覽 |
| 預期停留 | 2–3 分鐘 |
| 看完後應該知道 | ① SpotOn 想解決什麼問題　② 它實際怎麼運作　③ 正式版在哪裡 |

## 3. 頁面結構（由上到下）

1. **開場（Hero）**：產品名、一句話定位、往下捲的引導按鈕
2. **情境小測驗**：4 題關於「你平常怎麼選位」的問題，結果帶出痛點
3. **迷你選位體驗**：仿正式版的四欄滾輪選位器（樓／門／排／號），選完顯示座位資訊卡
4. **核心功能介紹**：3 張功能卡片說明正式版的主要功能
5. **前往正式版**：連結到 Vercel 正式版與頁尾資訊

## 4. 互動功能規格

### 4.1 情境小測驗（帶出痛點）

- 一次顯示一題，點選答案後自動進入下一題，上方有進度條（1/4、2/4…）
- 題目設計：

| # | 題目 | 選項 |
|---|---|---|
| 1 | 上次買表演票時，你主要怎麼決定座位？ | 看價格／越靠近舞台越好／跟朋友或網路推薦／有位子就好 |
| 2 | 下單前，你知道那個位置看出去是什麼樣子嗎？ | 很清楚／大概想像得到／不知道，進場才知道 |
| 3 | 你知道同一個音樂廳，坐不同區聽到的聲音會不一樣嗎？ | 知道，而且會考慮／聽過，但選位時沒想過／第一次聽說 |
| 4 | 你有沒有過「早知道就不坐這裡」的經驗？ | 有／沒有／不確定，沒比較過 |

- 計分：每題有一個「靠直覺／資訊不足」的選項傾向，依累計分數給出 3 種結果：
  - **直覺派選位者**（多數題目靠猜）
  - **半資訊選位者**（有些概念但缺乏具體資訊）
  - **資深選位者**（已有選位意識）
- 每種結果都要連結到同一個結論：「不論哪一型，買票時都缺少『坐下去會看到、聽到什麼』的具體資訊」，並有按鈕跳到迷你選位體驗
- 可「重新作答」

### 4.2 迷你選位體驗

- **四欄滾輪選位器**：樓、門、排、號，仿 iPhone 計時器滾輪，使用 scroll-snap 讓數字吸附在中央
  - 換樓層時，門號選項跟著變；換門時，排數跟著變；換排時，座位數跟著變
  - 樓層／門號／每排座位數使用正式版 `seatPicker.js` 的衛武營音樂廳設定
- 電腦版也可用滑鼠滾輪或點選數字操作
- 按「查看這個座位」後顯示**座位資訊卡**：
  - 座位標示（例：7 門・第 3 排・12 號／二樓主廳）
  - 該區的**視野截圖**
  - **聲學特性標籤**（例：聲場均衡、俯視舞台、殘響豐富）
  - **視野資訊**：距離、方向、遮擋
  - **經驗程度切換**：無音樂背景／初學者／中階／專業，四種版本的座位描述即時切換——這是 SpotOn「個人化描述」的核心賣點
- 提示文字說明：這裡展示的是 8 個代表區域，正式版涵蓋更多

### 4.3 其他互動細節

- 頂部固定導覽列，可跳到各區塊，捲動時標示目前位置
- 區塊進入畫面時有淡入動畫（尊重使用者「減少動態」的系統設定）

## 5. 資料來源

全部使用 SpotOn 正式版專案中的真實資料，不需要連網或後端：

| 資料 | 來源檔案 | 用途 |

| 樓層、門號、每排座位數 | `src/stores/seatPicker.js` | 滾輪選位器的選項 |
| 門號 → 視角區域對照、聲學特性 | `src/stores/seatPicker.js` | 座位資訊卡的區域名稱與標籤 |

## 7. 技術規格

- **單一 `index.html` 檔案**，CSS 與 JavaScript 全部寫在檔案內
- 使用原生 HTML / CSS / JavaScript，不使用框架、不需要建置步驟
- 圖片壓縮為 JPEG 後以 base64 內嵌，確保真的只有一個檔案
- 不使用 Firebase、不呼叫 Claude API（純前端不能放 API 金鑰）
- 支援手機、平板、電腦瀏覽器
- 部署：GitHub Pages

## 8. 與正式版的差異

| | 正式版 SpotOn-Web | 本介紹頁 |
|---|---|---|
| 技術 | Vue 3 + Vite + Pinia + Firebase + Claude API | 單一 HTML、原生 JS |
| 帳號 | 需登入，經驗程度存在個人檔案 | 不登入，直接切換經驗程度 |
| 區域數量 | 24 個視角區域 | 8 個代表區域 |
| 活動探索 | 有（整合售票平台） | 只在功能介紹中說明 |
| 目的 | 實際使用 | 介紹與體驗 |

## 10. 部署步驟

1. 在 GitHub 建立新的 public repository（例：`spoton-intro`）
2. 上傳 `index.html` 與 `README.md`（本規格書）
3. Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)` → Save
4. 等 1–2 分鐘，網址為 `https://<帳號>.github.io/spoton-intro/`
